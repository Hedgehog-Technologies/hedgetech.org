## Overview

`ht_mlotool` is a FiveM resource that helps you customize and generate audio occlusion files for MLOs.

## Installation

1. Download the latest release (or clone the repository) into your server's `resources` folder.
2. Follow the build and setup steps in the repository README.
3. Add the resource to your `server.cfg` and restart.
