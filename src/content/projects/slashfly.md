## Overview

SlashFly adds a `/fly` command to singleplayer Minecraft.

## Installation

1. Install a supported mod loader for your Minecraft version.
2. Download the latest release from the sidebar.
3. Drop the `.jar` into your `mods` folder and launch the game.

## Usage

Run `/fly` in a singleplayer world.
